## 1. 数字の正本と、使ってはいけない数字

スライドに書く秒・µrad は、下の「使う」だけ。中間メモの17ケース集計（12.1 s、16.3 s、4.75 s、static 0.27 s）は提出稿の14ケースと母数が違うので使わない。

### 使う

予測（21ケース、nested leave-one-case-out）:

- 支配軸 test RMSE: 中央値 **4.9 µrad**、平均 **5.5 µrad**
- 生LOSの支配軸 RMS: 中央値 **615 µrad**
- 支配軸バイアス RMSE: in-sample 3.1 µrad / LOO 3.8 µrad
- 共有感度 `a`: MX / MY / PX / PY = **+30.6 / +28.6 / −28.1 / −28.7 µrad/K**
- 太陽面別の生RMS: MY **150–265**、PX **600–670**、MX **670–730**、PY **1180–1280** µrad
- Case 08（PY、全発熱）: 生 RMS **1250 µrad** → test RMSE **3.9 µrad**
- 難しいケース: Black 被覆で残差約 **13 µrad**、HOT で DC が数 µrad 残る、PROP 半電力で約 **16 µrad**

捕捉（COLD・標準表面の14ケース = Case 4–6, 8–9, 13–21。各ケースは周期定常後3軌道・301点。非熱は1 seed で Monte Carlo ではない）:

- 走査: 範囲 **±1600 µrad**、ステップ **120 µrad**、検出半径 **150 µrad**、滞在 **0.1 s/点**、最大 **729点**。被覆の穴はない（対角の半分 ≈ 85 µrad < 150 µrad）
- 熱のみ: 補正なし **14.6 s** → 階層モデル **0.10 s** → 熱真値 **0.10 s**。成功率はいずれも 100%。補正後の平均熱残差 **9.3 µrad**
- 非熱込み: 補正なし **19.2 s**、成功率 **98%** → 階層モデル **5.45 s**（約72%減）、成功率 **100%**。補正後の平均初期誤差 **448 µrad**
- 太陽面: MY は改善が小さい。PY は **37.3–39.5 s、成功率 88–97% → 1.3–1.8 s、100%**

残差 Fourier（予備。非熱込み、causal、K=2。代表2ケース）:

- Case 13（MY）: 全誤差を直接 Fourier すると全区間 1.39 s（初周 3.37 s、周1以降 0.39 s）。FF のあと残差 Fourier は全区間 **0.79 s**（初周 1.60 s、周1以降 **0.38 s**）
- Case 16（PY）: 直接 Fourier は全区間 13.2 s、成功率 98.7%（初周 **39.5 s**、周1以降 0.38 s）。FF + 残差 Fourier は全区間 **0.76 s**（初周 1.47 s、周1以降 **0.40 s**）
- 定数の残差更新だけでは、Case 13 の周1以降が 1.66 s → 1.35 s までしか落ちず、Fourier の 0.38 s に届かない

モデル式（本編で出すのはこの範囲）:

```text
θ_th = θ_LCT − θ_STT
θ_dom(t) ≈ b_case + a(sun) · ΔT(t)
ΔT(t) = T_sunface(t) − T_opposite(t)
b_case ≈ b0(sun) + c_prop · I_prop + c_pcdu · I_pcdu
θ_scan = θ_nom − θ_hat_th
```

固定16係数であることは口頭か隅に小さく。係数表の全数値は裏。非支配軸の DC（MX/PX で約 −600 µrad、MY/PY で約 +20 µrad）は、モデルの枚で一言触れる。ゼロにすると捕捉が壊れる、が理由。

衛星: 外形 0.6 m × 0.6 m × 1.0 m、A5052、基準温度 24 °C。STT は PZ、LCT は MZ、視線はおよそ −Z。内部発熱の代表は PROP 25 W（PY）、PCDU 10 W（MY）。STT/LCT は通信時を想定して基本 ON。

### 使ってはいけない

| 数字 | 出所 | 理由 |
|---|---|---|
| 2.43 s → 0.74 s、初期誤差 93.9 → 49.5 µrad、成功率 97.5% | 5月の mock | 仮想の熱バイアス。実解析ではない |
| 124.6 s、static 4.78 s、156.9 → 59.6 s、94.0 → 97.1% | 7月光RG | ステップ 40 µrad・検出半径 25 µrad の密な走査。通信ビーム級で、格子に穴があった |
| 12.1 s、16.3 → 4.75 s、static 0.27 s | 2026-08-16 メモの17ケース | 提出稿は14ケースに絞ったあとの数字が正 |
| 熱LOS「数十〜数百 µrad」を主オーダーとして残す | 5月 | 今回の解析では **150 µrad から 1 mrad 超**。数十 µrad は姿勢・較正済みアライメントの側 |
