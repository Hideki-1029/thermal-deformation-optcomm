## 1. 介さん — パネル温度の絶対値と、温度差

パネルの温度がケースごとにかなり異なる。重要なのは温度のバイアス成分ではなく、あくまでパネルごとの温度差か。

当たる主張:

- 階層モデルは、軌道内の変動を太陽面と反対面の温度差 \(\Delta T(t) = T_\mathrm{sunface}(t) - T_\mathrm{opposite}(t)\) で取り、ケースごとの平均は発熱フラグの \(b_\mathrm{case}\) に分けている
- Case 04 の図は、パネルごとに温度の絶対値がずれて見える
- その枚の箇条は「表面の温度は変動成分、内部発熱はバイアス成分に効く」となっている。論文の観察は、表面特性が振幅と残差の床、内部発熱がケース間の平均、である

聞きたいことは、パネル温度そのものの底上げ（共通モード）が LOS に効くのか、効くのは面のあいだの差だけなのか、という点。

## 2. 五十里先生 — 非熱誤差、とくにアライメント

非熱誤差の設定をどうしているか。アライメント誤差が 50 µrad / 1σ というのは緩すぎる条件な気もする。1 deg と仮定する場合もある。キャリブレーション等でなんとかするのかもしれないが、もう少し整理せよ。

当たる主張:

- 非熱の枚。アライメントは「ケースごとに一定の2軸残差、50 µrad/軸、1σ」。姿勢も 50 µrad/軸、1σ。ドリフトは振幅 30 µrad、周期 900 s。軌道は Sentinel-1 の TLE と高精度暦の差
- 赤文字は「特定衛星の誤差バジェット再現ではなく、GNSS 非搭載 LEO 小型衛星の共存シナリオ」
- 1 deg は約 1.7×10⁴ µrad。50 µrad は約 0.003 deg で、1 deg よりずっと小さい残差を置いている

5月の介さんへの回答では、アライメントは打ち上げ後ほぼ定常で、キャリブレーションや通信の繰り返しで減らせる、としていた。今日の指摘は、その「校正後の残差」と「校正前に置きうる 1 deg」を、同じ表の 50 µrad の中で混ぜないこと。

## 6. 輪講後の望月さん・五十里先生との議論

議論順は望月さん、五十里先生。輪講中の質問より一段進み、研究の切り分け、モデルをどこまで物理に寄せるか、軌道予測誤差の代表性、軌道上更新の必要性まで話した。

### 6.1 望月さん

まず高本側の研究を、次の問題として共有した。

- 光通信のリンク確立前には、軌道決定誤差と熱歪によるアライメント誤差が重なり、走査すべき不確定領域が広がる
- 予測できる熱成分を走査前に差し引けば、走査中心まわりの不確定性を減らし、捕捉時間を短縮できる
- ただし「軌道上のいかなる熱歪状態でも補償できる」という言い方をするなら、適用範囲を明示し、その範囲内で精度を示す必要がある

主な論点:

- **望月さんの研究との境界。** 同じ「温度から光学量の残差を補正する」研究なので、軌道予測誤差の有無だけでなく、いつ、何を、どの参照情報で補正するかを分ける必要がある
- **軌道上更新の必要性。** 未知の計測誤差まで軌道上で推定する枠組みを主研究にするのか。現行の固定係数で十分なら、更新機構を先に大きくしない方がよい。一方、打上げ後の取付ずれ、推進系作動、放射線劣化などによる遅いアライメント変化は残るため、長期的な再較正の余地はある
- **一次式の適用限界。** 現在の箱型衛星では `LOS ≈ b + a·ΔT` が効くが、搭載機器や内部パネルを増やした複雑な衛星でも同じ低次元式で表せるかは未確認。表せるなら、それ自体が一般化に向けた強い結果になる
- **捕捉後の情報利用。** 走査で相手を見つけた時点で、予測値と実際の捕捉方向との差が得られる。その残差でモデルを事後修正する、光通信固有の較正方法を調べる価値がある
- **走査則。** 熱モデルだけでなく、予測誤差の形に応じて走査順序や探索領域を変える余地がある
- **GNSS 非搭載という想定。** LEO の光通信衛星は GNSS を搭載している例が多い可能性がある。GNSS 非搭載を置くなら、実例、搭載率、または光通信そのものを航法に使うユースケースを確認する
- **軌道予測誤差が差別化になるか。** 現状の Sentinel-1 TLE と精密暦の差は、実際の GNSS 非搭載衛星が運用で持つ予測誤差より大きすぎる可能性があり、比較条件として適切か再確認が必要

### 6.2 五十里先生

中心となった問いは「物理ベースか、経験ベースか」。方向性としては、物理に基づく低次元化を研究の軸として見せる方がよい、という話だった。

- 物理ベースなら、なぜその温度を使うかだけでなく、センサや機器の最適配置まで議論できる
- すべてを機械学習で吸収したり、モデルを常時軌道上更新したりする必要はない。リアルタイム推定を入れるなら、不確実性または感度の大きい少数パラメータに限る考え方がある。KF のような高頻度更新でなくてもよい
- 固定してよい物理量と、軌道上で同定すべき量を切り分けることが重要
- 将来、望月さんの adaptive な学習系と組み合わせる二層構成はあり得る。ただし、まず高本側の物理的な役割を明確にする
- 物理ベースを主張するなら、現在より複雑で現実的な衛星モデルでも試した方がよい。MELCO の複雑で正確な衛星モデルを用いた研究で精度が出た例が挙がり、比較的小型の 50 kg 級モデルへの展開案も出た
- 経験ベースは、十分なデータと完成したモデルがあれば早く精度が出る一方、軌道上で学習データを集め終わるまで時間がかかる

軌道予測誤差については次が出た。

- 事前に軌道予測誤差が小さくなる軌道区間や条件があるか確認する。外乱が小さい区間、GNSS が高精度になる条件、TLE 更新間隔との関係を調べる
- Sentinel-1 の TLE 対精密暦という作り方自体は分かりやすいが、Sentinel-1 は条件が良く、かつ TLE は実運用の航法解よりかなり粗い可能性がある。現在の誤差波形の周期性も確認する
- 超小型衛星に近い実データ、または GNSS シミュレータの単機データを使って誤差の大きさと時間構造を見た方がよい。福田さんに相談する案と、軌道上衛星データを使う案が出た

### 6.3 この議論を踏まえた研究の置き方

現時点で、主研究を次のように置くのが最も明確。

1. 主役は、光リンク確立前に使う**熱 LOS の feedforward 予測**である。光学的な参照値がまだ無くても、温度と運用状態だけで最初の走査中心を動かせることが価値
2. 現行モデルは、完全な物理モデルではなく、**物理機構で特徴量と階層を選び、係数を高忠実度解析から同定した physics-guided empirical model** である
3. 軌道予測・姿勢・アライメント誤差は、熱補正後に残る探索床を作る外生誤差であり、それを推定すること自体は主貢献ではない
4. 捕捉後の残差更新は第二層である。まず初回捕捉を feedforward で軽くし、その後に得た光学残差で周期成分または少数パラメータを更新する
5. 望月さんとの差は、機械学習の有無よりも、**初回捕捉前の走査中心補正**対**編隊飛行中の相対航法・ミッション出力残差補償**に置く

したがって、「軌道上のいかなる熱状態にも対応」は現状では広すぎる。少なくとも今の検証範囲は、1つの箱型構体、4太陽面、主に COLD・標準表面・離散的な発熱モードである。Black 被覆、HOT、連続的な発熱量では残差が増えるため、「検証した熱環境・構体の範囲で、係数をケース間共有できる」と書く。

### 6.4 宿題

- GNSS 搭載／非搭載の光通信衛星の実例と、GNSS 非搭載を置くミッション上の理由を調べる
- Sentinel-1 TLE 誤差の代表性、更新間隔、周期性を確認し、超小型衛星の実データまたは GNSS シミュレータ出力に置き換えられるか検討する
- 取付ずれの初期値だけでなく、打上げ後の遅いドリフトを誤差モデルに入れる
- 捕捉後に得られる方向残差を用いた、光通信固有の再較正方法を調べる
- 予測分布に応じた走査範囲・走査順序を検討する
- より複雑な衛星モデルで、2点の `ΔT` と一次式がどこまで維持されるか確認する
- 物理から固定する量と、軌道上で更新する少数パラメータを明示する

## 7. 望月さんの最新スライド

資料: [`20261014_mochizuki_phd_thesis.pdf`](../literature/20261014_mochizuki_phd_thesis.pdf)（表紙日付 2026-10-14、49枚）

題は「熱変形・構造変動を考慮した編隊飛行のための多センサ高精密相対航法」。中核は、QPD、レーザー測距計、スターセンサ／ジャイロを統合する相対航法 EKF の後段に残差補償器を置く **Learning-Augmented EKF（LA-EKF）** である。

### 7.1 問題設定と提案手法

- 高精度編隊飛行では、各センサの計測精度だけでなく、センサ座標系とミッション機器座標系の関係が正確である必要がある
- 実際の取付姿勢・位置には、公称値、組立・打上げ由来の静的オフセット、温度で変化する熱変形成分がある
- EKF が公称取付値を固定して航法状態を推定すると、ミスアラインメントの一部が状態誤差へ吸収される。そのため、学習対象は物理的な取付誤差そのものではなく、EKF を通過した後にミッション出力へ残る**有効残差**である
- 基本 EKF は、2衛星間の相対位置・速度・姿勢・角速度の12状態を、QPD、レーザー測距計、スターセンサ／ジャイロから推定する
- 残差補償器は、多点温度と衛星間距離など、軌道上で連続取得できる特徴量から有効残差の条件付き平均を予測する。高精度なミッション基準値が間欠的に得られた時だけ補償器を更新する
- 補償器として、オフラインのバッチ推定、ニューラルネットワーク、オンラインの逐次最小二乗法（RLS）を同じ枠組みで比較する。EKF 本体は変えず、後段の補償器を運用条件で切り替えられる

### 7.2 評価と主な結果

ケーススタディは、3機編隊の赤外線干渉計 SEIRIOS。ミッション出力は光路差 OPD、入射角差、検出器上のスポット位置で、熱歪の影響が最も明瞭に出た OPD を中心に評価している。

- 真値側は、多ノード温度場と位置依存の熱弾性変形を含む高忠実度モデル。太陽 β 角を 0–90°、衛星間距離を 10 m と 50 m で振る
- 学習時と同じ 10 m 条件では、Batch、NN、RLS のいずれも OPD 誤差を約 0.02–0.03 mm RMS まで低減し、EKF 単体から10倍以上改善した
- 10 m で学習した補償器を 50 m にそのまま適用すると不足する。OPD 誤差の距離比例を使って正規化すると、Batch / NN は約 0.13–0.16 mm RMS まで改善する。参照値が得られる場合は RLS で追従できる
- NN は学習した β 角への依存が強く、β = 90°だけで学習して β = 0°へ適用した例では 0.597 mm まで悪化した。複数 β 角を学習すれば 0.016–0.044 mm 程度だが、未学習条件への適用は Batch の方が安定した
- 温度センサ雑音は 0.1 K 以下なら精度悪化が 4–7%程度に収まるが、1 K では補正効果がほぼ失われる
- 同定後に機器の位置関係が変わると Batch / NN は外れる。一方、RLS もミッション基準値が得られない期間は更新できず、同定済みの熱状態から離れるほど誤差が増える
- 運用案は、初期は事前学習不要の RLS、参照データ蓄積後に地上で Batch / NN を学習してアップリンクし、熱環境と参照値の有無で切り替えるもの
- 現状はシミュレーション評価が中心で、SEIRIOS 実験系による実機検証を今後行う

### 7.3 高本の研究との共通点と差分

| 軸 | 望月さん | 高本 |
|---|---|---|
| ミッション | 近距離の高精度編隊飛行、赤外線干渉計 | 遠距離の衛星光通信、PAT 粗捕捉 |
| 解きたい問題 | センサ取付誤差と熱変形が混入した相対航法から、ミッション座標系の正確度を回復 | 光フィードバックが無い捕捉前に、予測可能な熱 LOS を走査中心から引く |
| 基本推定器 | QPD・測距・STT/gyroを統合する EKF | EKF は置かず、熱 LOS の低次元 feedforward モデル |
| 補正対象 | EKF 後段のミッション出力有効残差。主評価量は OPD | STT–LCT 間の相対 LOS 角。評価量は捕捉時間と成功率 |
| 熱の表現 | 多ノード温度、衛星間距離などを特徴量にし、位置ごとの構造変動を表す | 太陽面と反対面の中心温度差 `ΔT`、太陽面、PROP / PCDU 状態に縮約 |
| 同定 | Batch、NN、RLS。間欠的なミッション基準値で学習・更新 | TD/Femap 真値から階層一次式を同定。主 feedforward は飛行中の光学参照値を必要としない |
| 軌道上更新 | 中心課題。RLS は参照取得時にオンライン更新 | 主結果では固定16係数。捕捉後の残差 Fourier は予備的な第二層 |
| 利用時点 | 編隊飛行中の継続的な相対航法とミッション出力補償 | 相手光をまだ見つけていない最初の粗捕捉から利用 |
| 非熱誤差 | 相対状態・取付誤差と熱歪が航法フィルタ内で混在 | 軌道予測、姿勢、アライメント、ドリフトを外生誤差として走査評価に加算 |
| 検証 | β角・距離を振った編隊干渉計シミュレーション。実機検証は今後 | 1つの箱型衛星の21熱ケースと14捕捉ケース。nested LOO。地上試験は未実施 |

重なるのは、「温度から直接観測しにくい光学系の残差を予測する」「高忠実度モデルまたは参照データから軽量な補正器を作る」「学習範囲外への一般化が課題」という部分。

差別化の本線は次の一文にまとめられる。

> 望月さんは、間欠的なミッション基準を使って編隊飛行の EKF 後段に残る OPD 等の有効残差を学習・更新する。高本は、光学基準をまだ取得できない初回粗捕捉の前に、2点温度差と運用状態だけで STT–LCT 熱 LOS を feedforward し、走査時間を減らす。

この境界なら、望月さんの研究が Batch / NN / RLS のどれを使うかに依存せず、高本側も将来 adaptive 更新を追加できる。逆に、「高本は物理、望月さんは機械学習」だけでは弱い。高本の係数も高忠実度解析から回帰しており、望月さんにも線形 Batch / RLS と物理モデルがあるためである。

### 7.4 こちらへ取り込める示唆

- **有効残差という定義。** 捕捉後に受信センサで見える残差は、純粋な熱変形そのものではなく、軌道・姿勢・アライメント・制御を通った後の残差である。第二層を設計するときは、熱だけを再同定すると言わず「捕捉系に残る有効残差」を学習対象にする
- **距離・幾何による正規化。** 望月さんの OPD は衛星間距離でスケールした。高本側でも、別のリンク距離・機器配置・バス寸法へ展開する際、どの係数が幾何量で正規化できるかを調べる価値がある
- **学習範囲の明示。** β角外挿で NN が崩れた結果は、こちらの Black / HOT / PROP半電力の残差増大と同じ問題。適用領域を明示し、領域外検出または再同定条件を決める
- **運用順序。** こちらは feedforward を初回から使い、参照残差が蓄積してから軽量な更新器を足す。望月さんの「初期 RLS → データ蓄積 → Batch / NN」という較正シーケンスは、第二層の設計候補になる
